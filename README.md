# Interactive Computer Image Map

This project displays a computer image with clickable areas highlighting key components such as the CPU, monitor, keyboard, and mouse.  
Clicking each area opens an image of the selected component.

## How It Works

- Uses an HTML `<map>` and `<area>` elements with coordinates to define clickable regions on the image.  
- Each region links to a corresponding image of the computer part.

## Usage

Open the `index.html` file in a browser to see the interactive image.  
*Note:* Image file paths are currently local and may need updating for web use.

## Technologies

- HTML5  
- Image Maps
